앱·웹 스튜디오 boundary의 백엔드·관리자 개발

인베스티

(주)인베스티가 운영한 앱·웹 스튜디오 boundary에서 2021년 9월부터 2023년 6월까지 Developer Manager로 일했습니다. 업종이 다른 플랫폼 다섯 곳의 백엔드와 운영자용 관리자 페이지를 개발했습니다.

담당 역할

해결할 과제

  • 할인, 지도, 정비·경매, 학원, 앨범까지 업종이 다른 서비스를 이어서 맡았습니다.
  • 서비스마다 사용자 화면 뒤의 서버와 운영자가 쓰는 관리자 페이지가 함께 필요했습니다.

  • 차량정비, 경매 플랫폼 · 22.02 – 22.06 · BE / ADMIN page DEV
  • 영어학원 페이지 리브랜딩 · 22.06 – 22.07 · BE / ADMIN page DEV
  • K-POP 앨범 플랫폼 · 22.07 – 23.06 · BE / ADMIN page DEV

박준성 약력 기준. 고객사 이름과 화면은 싣지 않았습니다.

구현한 내용

  • 플랫폼별로 백엔드와 관리자 페이지를 개발했습니다.
  • 기간이 겹치는 프로젝트를 함께 진행한 시기가 있었습니다(2021.12–2022.01, 2022.02–2022.04 등).
  • K-POP 앨범 플랫폼은 2022년 7월부터 2023년 6월까지 약 1년 동안 맡았습니다.
