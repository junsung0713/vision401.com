링크를 저장하고 기기 간에 이어 보는 웹 서비스

AirLinking

웹사이트 링크를 모바일과 웹 어디서나 저장하고 다시 볼 수 있게 한 웹 서비스입니다. 크롬 읽기목록에 링크를 넣을 수 없는 사람을 위해 만들었고, 폴더와 태그로 정리합니다.

프로젝트 정보

프로젝트
자체 서비스 (한성준 운영)
담당 역할
기획·개발·운영 (한성준, 팀 수행 이력)
작업 범위
서비스 기획 · 반응형 웹·PWA 개발 · 회원 인증·데이터 저장 · 한국어·영어 화면 · 배포·운영
기술
Next.js, Firebase Authentication, Cloud Firestore, Tailwind CSS, Vercel

해결할 과제

  • 크롬 읽기목록에 링크를 추가할 수 없는 환경이 있습니다.
  • 휴대폰에서 찾은 링크를 웹에서 이어 보기 번거롭습니다.

구현한 내용

  • 폴더와 태그로 링크를 정리하고 모든 기기에서 동기화되게 했습니다.
  • PWA 공유 대상으로 등록해 휴대폰 공유 메뉴에서 바로 저장하게 했습니다.
  • Firebase 인증과 Firestore로 회원과 링크 데이터를 관리합니다.
  • 한국어와 영어 화면을 함께 제공합니다.
